# Idea generator for 3D modelling

I often find myself wanting to practice my 3D modelling skills but end up spending more time deliberating over what to make than making it. Therefore I created this small project over the course of a few hours to address this issue. You can press generate and it will randomly select an object and a time limit (to stop you from procrastinating!). 

I learnt the basics of HTML, Javascript and CSS to create this little web project, to generate ideas, to make cool things.
